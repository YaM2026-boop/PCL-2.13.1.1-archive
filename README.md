## 使用

1. 把 exe 放到任意文件夹（路径不要含特殊字符）。
2. 双击运行。首次启动会在同目录生成 `PCL` 数据文件夹。
3. 默认 Minecraft 目录是当前用户的 `%APPDATA%\.minecraft`，可在设置里改。
4. **运行环境**：Windows 10 及以上 + .NET Framework 4.8（Win10 1803 之后系统自带；缺失时 PCL 会提示）。

单文件绿色版，不写注册表（2.13 起全局设置改存 `%APPDATA%\PCL\config.json`），删掉文件夹即卸载。

## ⚠️ 重要：不要让它在启动后自动更新

2.13.1.1 具备更新到 2.99 的能力，一旦升级就没有下载功能了。**让它保持原版的方法**：把 exe 设为只读。

- 手动：右键 `Plain Craft Launcher 2.exe` → 属性 → 勾选「只读」→ 确定。
- 或用仓库里的 `锁定更新.bat`（双击即可，纯设置文件属性，不改程序）。

设只读之后，若 PCL 尝试更新会失败并提示权限问题，这是**预期行为**，版本会停在 2.13.1.1。想主动更新时取消只读即可。
