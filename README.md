## 如何验证这个文件没有被投毒

**先算哈希**（PowerShell，或双击包里的 `验证.ps1`）：

```powershell
Get-FileHash ".\Plain Craft Launcher 2.exe" -Algorithm SHA256
```

结果必须等于上面那串 SHA256，一个字符都不能差。

**为什么这就够**：SHA256 是整个文件内容的指纹，改动任何一个字节（哪怕加一个 NOP、塞一段 shellcode）哈希都会完全变掉，而且无法伪造出相同哈希。所以哈希相同 = 你拿到的就是我声明的那个文件。

**那怎么证明"我声明的"就是"官方原版"？** 三条线索交叉验证：

1. **版本资源**：右键 exe → 属性 → 详细信息，应显示
   `Plain Craft Launcher` / `2.13.1.1` / `Copyright © 成都瓜皮龙科技有限公司`。
2. **PE 指纹**：文件头里的构建时间戳为 `0xD2AEE5FA`（PCL 用确定性构建，这是哈希式时间戳，不是真实日期，原版就长这样）。见 `SHA256SUMS.txt`。
3. **最有力的一条 —— 找别人对一次**：2026 年 8 月起就有大量玩家装了 2.13.1.1。任何一位让你算他的 SHA256，如果和你相同，说明你手里这份就是当年官方发布的那一份，中间没有被任何人改造过。见下面的[哈希见证](#哈希见证)。

## ⚠️ 重要：不要让它在启动后自动更新

2.13.1.1 具备更新到 2.99 的能力，一旦升级就没有下载功能了。**让它保持原版**：把 exe 设为只读。

- 手动：右键 exe → 属性 → 勾选「只读」。
- 或双击包里的 `锁定更新.bat`（只改文件属性，不碰程序）。

设只读后若 PCL 提示更新失败/权限问题，这是预期行为，版本会停在 2.13.1.1。

## 使用

1. 先校验哈希。
2. 放到任意文件夹（路径别含特殊字符），双击运行。
3. 首次启动会在同目录生成 `PCL` 数据文件夹；MC 目录默认 `%APPDATA%\.minecraft`。
4. 环境：Windows 10+ 与 .NET Framework 4.8（Win10 1803 后自带）。
